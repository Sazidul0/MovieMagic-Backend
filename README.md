# 🎬 Movie Magic – Backend

Movie Magic is a Node.js backend application designed to power movie-related features such as fetching movie data, managing user interactions, and more.

## 🚀 Getting Started

Follow the steps below to run the project locally.

---

## 📥 1. Clone the Repository

```bash
git clone https://github.com/Sazidul0/MovieMagic-Backend.git
```


## 📂 2. Navigate Into the Project Directory

```bash
cd MovieMagic-Backend
```

## 🔧 3. Create a .env File
Inside the project root, create a .env file and add the required environment variables.

```bash
PORT=5000
MONGO_URI=Your_MongoDB_URI
JWT_SECRET=JWT_Secret_key
```
## 📦 4. Install Dependencies

```bash
npm install
```

## ▶️ 5. Run the Server

```bash
node server.js
```
